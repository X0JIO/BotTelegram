# Руководство пользователя бота записи

## Роли и права

Откройте системную кнопку **Menu** Telegram и выберите **Помощь**. В руководстве каждый раздел открывается отдельной кнопкой: клиенты видят инструкцию клиента, администраторы — обе инструкции.

К этому же меню ведёт нижняя кнопка быстрого доступа **«📖 Помощь»**. В личном чате входящие сообщения пользователя удаляются после получения. Для переходов используйте кнопки интерфейса: бот обновляет экран на месте.

| Возможность | Клиент | Администратор |
|---|:---:|:---:|
| Смотреть календарь и свободные слоты | ✓ | ✓ |
| Записаться на свободное время | ✓ | ✓ |
| Просматривать занятость, описание и данные клиента | — | ✓ |
| Закрыть свободный слот для записи | — | ✓ |
| Изменить описание и важность занятого времени | — | ✓ |
| Снять занятость одного слота или всего дня | — | ✓ |

Права администратора выдаются по Telegram ID в `ADMIN_IDS` файла `.env`. Обычные пользователи не могут вызывать административные действия, даже если вручную отправят callback или команду.

## Клиентам

1. Откройте бота и отправьте `/start`.
2. В календаре выберите день с доступным временем. Компактные метки календаря:
   - `10🟢` — есть свободное время;
   - `10🟡` — осталось мало свободных мест;
   - `10❌` — мест нет, день нельзя выбрать;
   - `10·` — прошедший день.
3. Выберите свободное время (`🕒 14:00`) или нажмите **«Забронировать весь день»**, если все слоты на дату свободны. Занятые слоты с замком выбрать нельзя.
4. Отправьте обязательное описание бронирования (до 500 символов).
5. Дождитесь сообщения с подтверждением записи.

Бронь всего дня резервирует все слоты даты. Если к подтверждению хотя бы один слот уже занят, бот не создаст дневную бронь и покажет обновлённое расписание.

Кнопки **«Пред.»** и **«След.»** переключают месяц. На шаге описания кнопка **«Назад»** возвращает к выбору времени, а **«Отменить запись»** — к календарю. Команда `/cancel` также отменяет ввод. Если два человека выберут один слот одновременно, запись получит только первый; второму бот покажет предупреждение и обновит доступность.

У клиента есть нижняя кнопка **«Календарь»**. Она снова показывает календарь текущего месяца.

## Администраторам

После `/start` используйте нижнюю кнопку **«Управление календарём»**. Системная кнопка **Menu** Telegram содержит команды администратора; команда **Команды** открывает список действий. Если права выданы во время открытого чата, отправьте `/start` ещё раз.

### Посмотреть занятость

1. Нажмите **«Расписание и занятость»** для выбора даты или **«Занятость сегодня»**.
2. В календаре управления цвет дня показывает доступность: 🟢 много свободных слотов, 🟡 мало, ❌ нет доступных клиентам слотов. Администратор может открыть любой день, включая красный.
3. Кнопка **«Сегодня»** сразу открывает настройки текущего дня. Откройте дату, чтобы увидеть список всех слотов: занятых и свободных.
4. Нажмите время, чтобы открыть карточку. В ней показаны описание, важность, имя клиента, его `@username` и ссылка на профиль, если Telegram предоставил эти данные.

### Закрыть свободное время

1. Откройте дату и нажмите свободный слот.
2. Выберите **«Отметить занятым»**.
3. Слот сразу пропадёт из записи клиентов. Начальное описание — «Заблокировано администратором», важность — обычная.
4. Нажмите **«Изменить описание»**, отправьте текст отдельным сообщением. Для отмены отправьте `/cancel`.
5. При необходимости выберите важность: обычная, важная или срочная.

### Изменить запись или важность

Откройте занятую карточку. Можно изменить описание или назначить важность. Пометки используются для внутренней работы администратора и не меняют факт занятости.

### Освободить время

- Чтобы освободить один слот, нажмите **«Освободить слот»**, затем подтвердите действие.
- Чтобы снять всю занятость за дату, нажмите **«Освободить весь день»**, затем подтвердите.

После освобождения слот снова виден клиентам как доступный.

## Кнопка «Команды» для администратора

Откройте системное меню **Menu** в Telegram, выберите **Команды**, затем выберите операцию:

- **Настроить сегодня** — открыть сегодняшние слоты;
- **Выбрать дату** — просмотреть расписание;
- **Закрыть свободный слот** — выбрать дату и слот, затем закрыть его;
- **Описание и важность** — открыть занятую запись и изменить её данные;
- **Освободить слот или день** — выбрать запись и подтвердить снятие занятости.

Даты и время выбираются кнопками. Для закрытия слота, изменения записи и освобождения используйте карточку нужного времени. Важность выбирается из вариантов **обычная**, **важная** или **срочная**.

## Если в карточке нет имени или `@username`

Некоторые пользователи Telegram не задают публичный username, а старые записи могли быть созданы до сохранения данных профиля. В этом случае бот показывает доступное имя и ссылку на профиль без публичного `@username`.
